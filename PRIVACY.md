# Политика конфиденциальности AutoType for Google Docs

Дата вступления в силу: 11 ноября 2026 года.

AutoType for Google Docs не собирает, не продаёт и не передаёт персональные данные. Расширение не использует внешние серверы, аналитику, рекламу или сторонние API.

Введённый пользователем текст, скорость и позиция сохраняются только локально в браузере через `chrome.storage.local`. Данные используются исключительно для работы функций расширения и могут быть удалены удалением расширения или очисткой его локального хранилища.

Доступ к страницам Google Docs используется только для переноса текста в сфокусированное пользователем место документа. Расширение не читает содержимое документа, не изменяет историю правок, авторство или журналы активности. Разрешение на запись в буфер обмена используется только после явного нажатия кнопки копирования остатка текста.

Исходный код распространяется по лицензии MIT. Вопросы по политике можно направлять через раздел Issues репозитория проекта.
