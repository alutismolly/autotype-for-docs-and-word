# AutoType for Google Docs

Расширение Manifest V3 для Chrome и Edge, которое последовательно переносит подготовленный текст в открытый документ Google Docs. Данные хранятся только локально в `chrome.storage.local`; разрешение `unlimitedStorage` снимает обычную небольшую квоту хранилища для объёмных текстов, но фактический предел всё равно определяется памятью и диском браузера.

## Установка

1. Откройте эту папку в Visual Studio Code: **File → Open Folder**.
2. В Chrome откройте `chrome://extensions`, в Edge — `edge://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку проекта.
5. После изменения исходников нажимайте **Обновить** на карточке расширения и перезагружайте вкладку Google Docs.

## Проверка

1. Откройте документ на `docs.google.com`.
2. Разрешите редактирование и щёлкните в нужном месте документа.
3. Откройте расширение, вставьте текст, выберите скорость и нажмите **Старт**.
4. Проверьте паузу, продолжение и остановку на коротком тестовом тексте с несколькими абзацами.

## Ограничение Google Docs

Google Docs использует canvas и скрытый фрейм для обработки текста. Расширение отправляет ввод в официальный текстовый обработчик открытого документа и не обращается к Google Docs API, не читает содержимое документа и не подделывает историю, автора или журналы активности.

Если Google Docs блокирует ввод, расширение останавливается, сохраняет позицию и показывает **Скопировать оставшийся текст**. После копирования поставьте курсор в документ и нажмите `Ctrl+V`.
