# AutoType for Docs & Word

Расширение Manifest V3 для Chrome и Edge, которое последовательно переносит подготовленный текст в Google Docs или Word Online. Данные хранятся только локально в `chrome.storage.local`.

Версия 2 использует разрешение Chrome Debugger только для `Input.insertText`. Это позволяет вводить текст в canvas-редакторы Word и Google Docs, не выбирая поле названия документа. Во время ввода Chrome показывает стандартное уведомление об управлении вкладкой; подключение снимается при паузе, остановке или завершении.

## Установка

1. Откройте эту папку в Visual Studio Code: **File → Open Folder**.
2. В Chrome откройте `chrome://extensions`, в Edge — `edge://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку проекта.
5. После установки обязательно перезагрузите вкладку открытого документа.

## Проверка

1. Откройте документ на `docs.google.com` или в Word Online, включая документы SharePoint и OneDrive.
2. Разрешите редактирование и щёлкните в нужном месте документа.
3. Откройте расширение, вставьте текст, выберите скорость и нажмите **Старт**.
4. Проверьте паузу, продолжение и остановку на коротком тестовом тексте с несколькими абзацами.

## Ограничения редакторов

Google Docs и Word Online могут использовать canvas, скрытые поля и внутреннюю модель документа. Расширение работает только с открытым редактором и не читает содержимое документа.

Если редактор блокирует ввод, расширение останавливается, сохраняет позицию и показывает **Скопировать оставшийся текст**. После копирования поставьте курсор в документ и нажмите `Ctrl+V`.
